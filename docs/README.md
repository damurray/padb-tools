# Documentation

Start with **GETTING_STARTED.md**. The one-page cheatsheets are for people who just want the steps.

| Document | What it is |
|---|---|
| `GETTING_STARTED.md` | Orientation: what the tools are, which pipeline to use, where everything is |
| `Quick_Start.md` | Step-by-step: onboard a new pod |
| `PADB_Tools_Guide.md` | The full reference: every job key, plot type, tool and feature |
| `Interactive_Plots_User_Guide.md` | Using the interactive HTML views |
| `PADB_Analytic_Requirements.md` | What a pod / analytic must contain for each plot type |
| `PADBLOADER_WITH_PADB_TOOLS.md` | Using PadbLoader (Oracle extraction) together with padb-tools |
| `Simple_Mode_Cheatsheet.md`, `Interactive_Mode_Cheatsheet.md`, `Compare_Mode_Cheatsheet.md` | One-page steps for each mode |
| `Reduction_Study_Worked_Example.md` | Test-point reduction and sentinel study, worked through |
| `UHP_IddVsVgg_Case_Study.md`, `Spectral_Data_For_FS_Case_Study.md` | Case studies: onboarding a blank pod; a run that was too fast |
| `Training_Delivery_Checklist.md`, `Training_Setup_1Pager.md` (+ `.pdf`), `PADB_Simple_and_Interactive.pptx` | Training material |
| `V3_PLAN.md` | The v3.0 design plan and staged roadmap |
| `images/` | Screenshots used by the tutorials |

Local PDF copies of the main guides are built by `py scripts/build_help_pdfs.py` (they are not tracked in git).
